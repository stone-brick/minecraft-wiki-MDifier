## [0.1.0] - 2026-06-15

### Added

- Initial release
- Multi-language support (zh, en, ja)
- MediaWiki API fetching with HTML fallback
- Template expansion via action=bucket and action=parse
- Bucket API support for Trade uses, Trade sources, Crafting usage, Mob spawn table
- 30+ common templates auto-expanded
- mcui parsing for crafting table/furnace/loom/smithing table
- Color code conversion
- CLI and Python library API
- Persistent template cache
- Batch conversion with concurrency
- Cross-language batch processing
